# Hexa pack

Página web estática creada a partir del documento `Hexa avocado Informe Final (3).docx`.

## Archivos principales

- `index.html`: página web del informe.
- `style.css`: estilos visuales con paleta azul basada en `#1C2B5C`.
- `assets/images/`: imágenes extraídas del Word actualizado y ordenadas por aparición.
- `image-map.md`: documentación del título y ubicación narrativa de cada imagen.
- `tools/extract_docx.py`: extractor reproducible del contenido e imágenes del Word.

Para visualizar la página, abre `index.html` en el navegador.
